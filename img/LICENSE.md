# Pictures in this folder: CC0 (public domain)

Every file in `img/` is an original work. Each picture was drawn by hand, as SVG
markup, for this project.

Nothing here was copied or downloaded from anywhere else. No icon sets, no clip art,
no fonts, no photos and no traced images were used.

All of these pictures are dedicated to the public domain under
**CC0 1.0 Universal**. You may copy, change and share them, for any purpose, without
asking and without giving credit.

https://creativecommons.org/publicdomain/zero/1.0/

## What is in each folder

| Folder | What it holds |
|---|---|
| `img/icons/` | The small line pictures for the lessons on the Trail, one per lesson idea. |
| `img/worlds/` | The eight round emblems, one for each world on the Trail (`w0.svg` to `w7.svg`). |
| `img/ranks/` | The ten round emblems, one for each title a learner can reach. |
| `img/badges/` | The round medals, one for each badge. |
| `img/brand/` | The site pictures: the wheel logo, the lotus shown beside points, the stepping stone for the map, the check mark, the open book, and the home page banner (`hero.svg`). |

## How they are made

- Plain SVG only: no scripts, no embedded images, no outside links.
- One shared palette of gold, dark yellow, orange, cream and dark brown.
- Each file has a short title so screen readers can name it.
